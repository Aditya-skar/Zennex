# SIMSOR – Android & iOS (Capacitor)

For **App Store / Play Store** publishing, see **[STORE_RELEASE.md](./STORE_RELEASE.md)**.

The web app is mobile-first. Native shells use **Capacitor 8**.

## Prerequisites

| Platform | Need |
|----------|------|
| **Android** | [Android Studio](https://developer.android.com/studio) + JDK 17+ |
| **iOS** | macOS + [Xcode](https://developer.apple.com/xcode/) 15+ (cannot build iOS on Windows) |
| Both | Node 20+ |

## One-time setup

```bash
cd frontend
npm install
npx cap add android
npx cap add ios    # macOS only
```

Copy env template when you have a backend:

```bash
cp .env.example .env
# set VITE_API_URL=http://YOUR_API_HOST:8000
```

## Daily workflow

```bash
# 1) Build web assets + sync into native projects
npm run cap:sync

# 2) Open native IDE
npm run cap:android   # Android Studio
npm run cap:ios       # Xcode (Mac)
```

Or run on a device/emulator from the CLI:

```bash
npx cap run android
npx cap run ios
```

### Live reload (optional)

While `npm run dev` is running, temporarily set in `capacitor.config.json`:

```json
"server": { "url": "http://YOUR_LAN_IP:5173", "cleartext": true }
```

Then `npx cap sync` and run the app. Remove `server.url` for production builds.

## Backend later

- UI still uses local mocks until `VITE_API_URL` is set.
- HTTP helpers live in `src/api/client.ts` and `src/api/endpoints.ts`.
- Use `isBackendEnabled()` before switching a screen from mock → API.
- Auth token key: `simsor-auth-token` (Bearer).

### Suggested API shape (stubs already match)

| Method | Path | Use |
|--------|------|-----|
| POST | `/api/auth/login` | Login |
| POST | `/api/auth/signup` | Signup |
| GET | `/api/me` | Current user |
| PATCH | `/api/me` | Profile + interests |
| GET | `/api/events` | Nearby events |
| POST | `/api/events` | Create event |

## Notes

- Portrait only (manifest + Capacitor).
- Safe areas use `viewport-fit=cover` + CSS `env(safe-area-inset-*)`.
- Android back button closes overlays first, then history, then exits.
- `android/` and `ios/` are generated by Capacitor — run `cap add` if missing.
